# Restored source project

This project was reconstructed from the distributed avecoins-fabric-26.2-2.5.jar.
Java files were decompiled with CFR; non-class resources (Fabric metadata, mixin config,
assets, translations, recipes, and licenses) were extracted from the supplied JAR.

Decompiled sources require compile validation and may need manual repair. This is a
reconstruction from bytecode, not the original developer source tree.
